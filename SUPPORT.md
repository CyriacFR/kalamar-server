# Getting help

- **The documentation is the reference**: the [README](README.md), the [documentation index](docs/README.md) and, to
  run a server, [docs/operator-first-steps.md](docs/operator-first-steps.md).
- **A bug** in the reference server, the relay, the test kit or the installer, or **an idea**: an issue, with one of
  the forms. Search the open issues first.
- **Code**: a pull request ([CONTRIBUTING.md](CONTRIBUTING.md)).
- **A security problem**: privately, as [SECURITY.md](SECURITY.md) explains; never in a public issue.
- **A problem with a server you play on** (accounts, bans, rules, a match result): that server's operator. This project
  runs no server and cannot act on anyone's server.
- **The launcher or the game**: the Kalamar repository (engine and launcher).

There is no private support and no discussion forum, and no answer is guaranteed: the project is maintained by
volunteers in their free time.

No help is given, here or in any channel of the project, to obtain a game, its update, keys or firmware.
